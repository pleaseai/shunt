Adding an AuthMode touches config.rs (enum ~2317, store_family ~3290, pool_scan ~3329, validate ~4790/4884/5010), config/presets.rs, config/upstreams.rs (AuthMap), auth/mod.rs (Credential + resolve_credential), adapters/responses (request.rs credential injection, mod.rs matches!(ChatgptOauth|XaiOauth), pool.rs store_family forks), admin/mod.rs (pool/patch match arms), usage.rs, usage_poll.rs, init.rs credential_source, accounts.rs StoreFamily, auth/shared.rs inline-identity match.
Closest template is XaiOauth (docs/m18-xai-multi-account.md, tests/xai_multi_account.rs).
main.rs `Command::Login` is destructured with all 5 fields in tests (no `..`), so adding a clap field to Login breaks parse tests; reuse `--manual`/`--name`.
Site sidebar is hand-listed in site/src/lib/i18n.ts (not autogenerated); codex/xai pages live under guides/, not providers/.
**Why:** saves re-deriving the exhaustive-match map. **How to apply:** re-grep `AuthMode::` before relying on line numbers.
